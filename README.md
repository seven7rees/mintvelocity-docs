# Mintvelocity

Mintvelocity is a community-run Solana launchpad: a token standard built for programmable hooks, a DEX built around them, and a launchpad on top. It is forked from the open-source (Apache-2.0) on-chain stack of Bordrless, which shut down on November 4, 2026.

**Status: pre-launch.** The code is forked and the site is built. What is left is the deploy: devnet test first, then mainnet.
